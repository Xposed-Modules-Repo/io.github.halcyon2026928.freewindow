# 灵动坞OS

ColorOS/realmeUI自由小窗强化模块

## 功能

- 隐藏自由小窗底部的小横条
- 隐藏自由小窗顶部菜单栏
- 隐藏均不影响自由小窗手势操作
- 静态灵动窗口(继承贴边保活)
- 贴边保活（功耗会增加，介意的可关闭）
- 解除最小化数量限制(最多12个，无上限你设备顶不住)

## 适用系统

- 真我GT5/真我GT8 pro最新系统版本 已测试
- 理论上欧加真所有设备通用，如遇问题请提 Issue或者找酷安作者@时安Halcyon

## 使用方法

1. 安装本模块 APK
2. 在 LSPosed 中启用模块
3. 勾选 **「系统框架」**（android）作用域
4. 重启手机
5. 提示需要重启的功能才需要重启设备生效，没提示需要重启的，开关功能只需重新打开自由小窗/坞窗即可生效
6. 坞窗功能继承贴边保活策略
7. 目前坞窗里的应用卡片均为静态画面(不影响保活)
